Made for the terminal

A familiar, focused workflow.

Vim-style control throughout the OpenCode TUI, built with the official plugin API and no upstream source changes.

01 / MODAL PROMPT

Insert when you need it

Press Esc to enter NORMAL mode. Use Vim motions, then return to editing with a familiar insert command.

Esc→iao
02 / LEADER MENU

Commands, in reach

Open a grouped menu with Space. Browse actions with j/k and run them with Enter.

Space→group→Enter
03 / NAVIGATION

Move through the conversation

Scroll line by line, page by page, or jump directly to the first and latest messages.

jkCtrl+fggG
04 / COMMANDS

Open the command palette

Use the familiar colon command to access OpenCode’s command panel from NORMAL mode.

:open commands
05 / CONTEXT

Know your mode and place

The home footer shows NORMAL or INSERT and your current working directory. Recent sessions appear on the home screen.

NORMAL~/project
06 / PERSONALITY

Oceanblack, included

A custom Oceanblack theme installs and activates with the plugin for a cohesive terminal experience.

Up and running

Install in a few steps.

Requires Bun and OpenCode. Keep the OpenTUI dependency versions compatible with the versions bundled in your OpenCode install.

1. Clone and install

git clone https://github.com/iamcheyan/opencode-vim.git cd opencode-vim bun install

2. Register the plugin

Add the absolute path to index.tsx in ~/.config/opencode/tui.json:

{ "$schema": "https://opencode.ai/tui.json", "plugin": ["/absolute/path/opencode-vim/index.tsx"] }
