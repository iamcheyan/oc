从源码编译

开始使用 oc-vim。

仓库包含完整的 OpenCode fork。构建脚本会为当前机器编译 TUI 集成和 CLI。

1. 克隆仓库

git clone https://github.com/iamcheyan/oc.git cd oc

2. 编译并启动

编译产物位于 fork/dist/。Linux x64 示例：

bash fork/build.sh ./fork/dist/oc-vim-linux-x64/bin/oc-vim
