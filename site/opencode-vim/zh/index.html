为终端而生

熟悉、专注的操作体验。

通过官方插件 API 为 OpenCode TUI 提供 Vim 风格操作，无需修改上游源码。

01 / 模态输入

需要时进入插入模式

按 Esc 进入 NORMAL 模式，使用 Vim 移动命令，再用熟悉的插入命令继续编辑。

Esc→iao
02 / 快捷菜单

常用命令触手可及

按 Space 打开分组菜单，用 j/k 浏览操作，按 Enter 执行。

Space→分组→Enter
03 / 导航

轻松浏览对话

逐行或逐页滚动，也可直接跳到第一条或最新消息。

jkCtrl+fggG
04 / 命令

打开命令面板

在 NORMAL 模式按熟悉的冒号键，打开 OpenCode 命令面板。

:打开命令
05 / 状态提示

随时了解模式与目录

首页状态栏显示 NORMAL 或 INSERT 模式及当前工作目录；首页底部还会列出最近会话。

NORMAL~/project
06 / 主题风格

内置 Oceanblack 主题

插件会自动安装并启用 Oceanblack 自定义主题，保持终端界面风格统一。

快速开始

几步即可安装。

需要 Bun 和 OpenCode。请确保 OpenTUI 依赖版本与当前 OpenCode 内置版本兼容。

1. 克隆并安装依赖

git clone https://github.com/iamcheyan/opencode-vim.git cd opencode-vim bun install

2. 注册插件

在 ~/.config/opencode/tui.json 中，将 index.tsx 的绝对路径加入插件列表：

{ "$schema": "https://opencode.ai/tui.json", "plugin": ["/absolute/path/opencode-vim/index.tsx"] }
开始使用
