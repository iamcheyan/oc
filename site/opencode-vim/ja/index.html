Vim を中心に再設計したターミナル。

oc-vim が提供する体験：Vim 状態マシン、ネイティブ Leader レイヤー、上流完全互換のセッションストリーミング、単一バイナリ。

01 / VIM モード

モーダル操作と自由な移動

NORMAL、INSERT、VISUAL をスムーズに遷移。慣れ親しんだ行移動（j/k）、ファイル先頭/末尾（gg/G）、範囲選択に対応。

02 / LEADER メニュー

上流ネイティブ指令への直接連携

Space を押すだけでグループ化メニューを展開。モデル切り替え、セッション履歴、Git diff など上流の標準機能へ直接アクセス。

03 / モデル自動記憶

外部 Provider 対応と即時切り替え

直近に選択したモデルを自動記憶。セッション内の即時ホット切り替えをサポートし、DeepSeek、EvoMap、Ollama、Kimi 等に標準対応。

ソースからビルド

oc-vim を始める。

リポジトリをクローンして、コマンド 1 つでスタンドアロン実行ファイルをビルドできます。

1. リポジトリをクローン

完全な履歴と独立フロントエンドを含むリポジトリを取得：

git clone https://github.com/iamcheyan/oc.git cd oc

2. ビルドして実行

ビルドスクリプトを実行すると fork/dist/ に生成されます：

bash fork/build.sh ./fork/dist/oc-vim-linux-x64/bin/oc-vim
