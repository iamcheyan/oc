ターミナルのために

慣れ親しんだ集中できる操作。

公式プラグイン API を使って OpenCode TUI 全体に Vim 風操作を追加します。上流ソースの変更は不要です。

01 / モーダル入力

必要なときに挿入モードへ

Esc で NORMAL モードに入り、Vim の移動操作を使えます。おなじみの挿入コマンドで編集に戻れます。

Esc→iao
02 / リーダーメニュー

コマンドにすぐアクセス

Space でグループメニューを開き、j/k で項目を選び、Enter で実行します。

Space→グループ→Enter
03 / ナビゲーション

会話を自在に移動

1 行または 1 ページずつスクロール。最初や最新のメッセージにも直接移動できます。

jkCtrl+fggG
04 / コマンド

コマンドパネルを開く

NORMAL モードでおなじみのコロンキーを押すと、OpenCode のコマンドパネルが開きます。

:コマンドを開く
05 / 状態表示

モードと作業場所を確認

ホームのフッターに NORMAL / INSERT と現在の作業ディレクトリを表示。最近のセッションもホーム画面に表示します。

NORMAL~/project
06 / テーマ

Oceanblack を同梱

カスタム Oceanblack テーマをプラグインと一緒にインストールして有効化し、統一感のある画面にします。

●●●
すぐに開始

数ステップでインストール。

Bun と OpenCode が必要です。OpenTUI の依存バージョンは、利用中の OpenCode に同梱されたものと互換性を保ってください。

1. クローンして依存関係を導入

git clone https://github.com/iamcheyan/opencode-vim.git cd opencode-vim bun install

2. プラグインを登録

~/.config/opencode/tui.json のプラグイン一覧に、index.tsx の絶対パスを追加します：

{ "$schema": "https://opencode.ai/tui.json", "plugin": ["/absolute/path/opencode-vim/index.tsx"] }
準備ができたら
