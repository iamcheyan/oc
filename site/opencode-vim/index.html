Build from source

Get oc-vim running.

The repository contains the full OpenCode fork. The build script compiles the TUI integration and CLI for the current machine.

1. Clone the repository

git clone https://github.com/iamcheyan/oc.git cd oc

2. Build and launch

The build writes the executable under fork/dist/. For Linux x64:

bash fork/build.sh ./fork/dist/oc-vim-linux-x64/bin/oc-vim
