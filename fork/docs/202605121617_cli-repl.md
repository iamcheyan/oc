# CLI REPL 模块

## 概述

`packages/opencode/src/cli/cmd/cli.ts` 实现了一个交互式命令行 REPL (Read-Eval-Print Loop) 界面，允许用户在终端中与 opencode 进行实时对话交互。

## 核心功能

### 1. 会话管理

- **创建新会话**: `/new` 命令创建新的对话会话
- **继续会话**: 通过 `--session` 或 `--continue` 参数继续已有会话
- **会话列表**: `/sessions` 命令显示最近的会话

### 2. 模型与代理切换

- **模型切换**: `/model [provider/model]` 查看或切换使用的模型
- **代理切换**: `/agent [name]` 查看或切换使用的代理
- **思维链显示**: `/thinking` 切换推理过程的可视化

### 3. 工具调用渲染

为各种工具提供简洁的输出格式：

| 工具 | 图标 | 示例输出 |
|------|------|----------|
| Glob | ✱ | `Glob "*.ts" in src` |
| Grep | ✱ | `Grep "pattern" in lib · 12 matches` |
| Read | → | `Read file.ts` |
| Write | ← | `Write output.ts` |
| Edit | ← | `Edit config.json` |
| WebFetch | % | `WebFetch https://...` |
| WebSearch | ◈ | `Search "query"` |
| Task | ✓/✗/• | `Description · Agent Agent` |
| Skill | ◇ | `Skill "effect"` |
| Shell | $ | `npm run build` |
| Todo | ☰ | `Todos · 5 items` |

### 4. 事件驱动架构

通过订阅事件流 (`sdk.event.subscribe`) 实时处理：

- `message.updated` - 消息更新
- `message.part.updated` - 消息部分更新（工具、文本、子任务）
- `message.part.delta` - 流式文本/推理输出
- `permission.asked` - 权限请求处理
- `session.error` - 会话错误
- `session.status` - 会话状态变化

### 5. 交互特性

- **Tab 自动补全**: 对斜杠命令提供补全
- **中断处理**: Ctrl+C 中断当前操作，双击退出
- **权限控制**: `--dangerously-skip-permissions` 跳过权限确认
- **初始提示**: `--prompt` 参数预先发送提示

## 命令行参数

| 参数 | 简写 | 说明 |
|------|------|------|
| `--model` | `-m` | 指定模型 (provider/model 格式) |
| `--agent` | | 指定代理 |
| `--session` | `-s` | 继续指定会话 |
| `--prompt` | | 初始提示内容 |
| `--continue` | `-c` | 继续最近会话 |
| `--thinking` | | 显示推理过程 |
| `--dangerously-skip-permissions` | | 自动批准权限 |
| `--dir` | | 工作目录 |

## 设计意图

1. **轻量级交互**: 提供比完整 TUI 更轻量的终端交互方式
2. **实时反馈**: 通过事件流实现工具执行的实时可视化
3. **可扩展性**: 工具渲染函数独立，便于添加新工具支持
4. **用户友好**: 自动补全、中断恢复、清晰的错误提示

## 启动流程

```
bootstrap() → 初始化 SDK → 创建/恢复会话 → 选择模型 → 订阅事件 → 进入 REPL 循环
```

## 与 TUI 的区别

| 特性 | CLI REPL | TUI |
|------|----------|-----|
| 依赖 | 仅需 TTY | 需要 Ink (React) |
| 界面 | 纯文本流 | 富组件界面 |
| 适用场景 | 快速交互、脚本集成 | 完整交互体验 |
| 资源占用 | 低 | 较高 |

## 当前状态

**该模块未被集成到主入口。**

`CliCommand` 在 `packages/opencode/src/cli/cmd/cli.ts` 中已完整实现，但：

2. 未通过 `.command(CliCommand)` 注册到 yargs

### 集成方法

在 `packages/opencode/src/index.ts` 中添加：

```ts
import { CliCommand } from "./cli/cmd/cli"
// ... 其他 imports

// 在 .command() 链中添加
.command(CliCommand)
```
