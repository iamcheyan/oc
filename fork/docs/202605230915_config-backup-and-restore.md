# OpenCode 配置打包备份与恢复功能文档

本文档详细描述了在 `opencode-vim` 模式下实现的**全局配置打包备份与恢复功能**的技术原理、用户交互界面以及使用指南。

---

## 1. 技术背景与设计理念

由于 OpenCode 支持多谷歌账号的 OAuth 自动轮换（由 `opencode-antigravity-auth` 插件管理）以及第三方 API Key 的个性化配置，用户在换新电脑或多设备开发时，常常面临复杂的账号重新授权和配置迁移问题。

为了解决这个问题，本功能旨在为用户提供**极简的一键导出与导入配置机制**：
* **免加密、无损保留**：由于备份文件默认存储在本地用户私有目录（`~`）或指定安全路径中，不随项目上传至公共 Git，因此 API Keys、凭证、Token 在备份包中以明文拼合，**确保在新机恢复后 100% 能够直接免密登录**。
* **单文件容器化拼合（JSON Container）**：
  * **备份时**：递归扫描全局配置文件夹，将所有零散的配置文件（包括 `opencode.json`、`antigravity-accounts.json`、`themes/*` 等）**扁平化拼合**进单一的 JSON 格式备份文件。
  * **恢复时**：解析单个 JSON 备份文件，自动在新设备上**重构目录树并精准拆分还原**所有独立文件。
  * **跨平台 100% 稳定**：放弃了 `zip` 或 `tar` 等依赖系统环境（不同 OS 命令参数不同、可能缺少命令、或 node 二进制依赖编译失败）的压缩方案，完全依靠 Node.js 原生的高效文件读写，做到绝对的跨操作系统兼容。

---

## 2. 备份与恢复的技术规范

### 2.1 备份对象
程序会递归扫描以下全局 OpenCode 配置目录之一（按存在优先级）：
1. `process.env.OPENCODE_CONFIG_DIR` （若设置了自定义路径）
2. `~/.config/opencode` （标准默认路径）
3. `~/.opencode` （备用全局路径）

**排除策略**：自动忽略 `node_modules/`、`.git/` 以及调试日志文件夹 `antigravity-logs/`，仅打包关键的核心配置文件和自定义主题。

### 2.2 备份文件结构 (JSON Schema)
```json
{
  "version": 1,
  "timestamp": 1779490000000,
  "files": {
    "opencode.json": "{ ... 插件声明与本地模型配置 ... }",
    "antigravity-accounts.json": "{ ... 两个谷歌账号的 OAuth 刷新凭证及设备指纹 ... }",
    "antigravity.json": "{ ... 插件运行参数 ... }",
    "themes/my-custom-theme.json": "{ ... 用户自定义 TUI 主题 ... }"
  }
}
```

### 2.3 恢复防灾备份机制 (Safeguard)
为了防止用户误用旧配置覆盖当前最新的有效配置，程序在**恢复写入前**会触发**自动防灾隔离**：
* 自动扫描当前的配置，将其扁平化打包并写入至用户主目录 `~/opencode-safety-backup-[timestamp].json`。
* 即使恢复了错误的备份包，用户也可以随时使用该防灾文件一键撤销并恢复之前的状态。

## 3. 使用方法与 TUI 交互指南

在 OpenCode Vim 模式（Vim 模式）下，可以通过 **Leader Menu 快捷键组** 非常直观地使用本功能：

### 3.1 备份配置 (Backup)
1. **触发快捷键**：按下 `空格` 激活 Leader 状态，接着输入 `u` (UI 组)，最后输入 `b` (Backup)。
2. **交互界面**：
   * 弹窗上方显示：`Backup OpenCode All Configs`
   * 系统会自动为您生成默认的备份路径，显示在专属输入框中：`~/opencode-backup-[YYYYMMDDHHmmssSSS].json`
   * **输入自定义路径**：如果不想存放在默认路径，直接按 **`c` 键**，专属输入框的边框将变成**亮橙黄色**。此时您可以使用键盘**直接输入自定义路径**（例如 `/Users/yourname/Desktop/my-config.json`），输入的内容会在闪烁的光标 `█` 前实时显示，支持使用 **Backspace（退格键）** 删除修改。
3. **执行备份**：按 **Enter 键**，程序执行打包并切换至成功页面，会以绿色符号清晰列出所有已打包并写入备份包的独立文件列表。

### 3.2 恢复配置 (Restore)
1. **触发快捷键**：按下 `空格` 激活 Leader 状态，输入 `u` (UI 组)，最后输入 `e` (R[e]store)。
2. **交互界面**：
   * 专属输入框的边框亮起，右侧光标 `█` 持续闪烁。
   * 直接打字输入你在前一台电脑上导出的备份文件路径（例如 `~/opencode-backup-20260523091530123.json`）。
3. **执行恢复**：按 **Enter 键**，程序将自动完成解包拆分与目录重构。
   * 恢复成功后，界面将提示：`Restore completed successfully!` 并绿色标注本次操作的防灾备份包存放地址（以便用户随时回滚）。

## 4. 常见问题 (FAQ)

#### Q1: 恢复到新电脑后，插件需要我手动重新下载吗？
**不需要。** `opencode.json` 中保存了配置 `"plugin": ["opencode-antigravity-auth@latest"]`。新电脑上的 OpenCode 启动时只要读到这个声明，就会在后台自动去 npm 下载并挂载对应的全部插件。

#### Q2: 如果在新电脑恢复后，无法成功免密登录怎么办？
通常拷贝 `antigravity-accounts.json` 中的 Refresh Token 在 95% 以上的情况下都可直接登录。如果登录状态失效，通常是因为：
* 您在 Google 安全中心主动注销了相关 IDE / App 的 OAuth 授权。
* 谷歌检测到新设备的 IP 物理跨度极大，安全锁主动使 Token 挂起。
此时您只需要在新电脑的终端上重新运行一次 `opencode auth login` 扫码认证即可，其他的模型列表和主题设置都会完美保留。
