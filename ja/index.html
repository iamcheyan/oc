集中できるターミナル操作

Vim を中心にした OpenCode。

oc fork が保守するターミナル体験。Vim モード、直接的なナビゲーション、コンパクトな画面、単体実行ファイルを提供します。

01 / VIM モード

Vim の操作で編集

INSERT と NORMAL を切り替え、使い慣れた Vim の移動操作を使えます。

NORMAL·INSERT
02 / LEADER メニュー

操作にすぐアクセス

Space でグループメニューを開き、キーボードで操作を選んで実行します。

INSERT·Space
03 / 会話ナビゲーション

セッション内を移動

j/k、gg/G、ページ移動で会話をすばやく閲覧できます。

Space·j k
04 / コンパクトな TUI

作業に集中

fork 独自のホーム画面とセッション画面で、端末 UI を見やすく保ちます。

j k·gg G
05 / 設定

Vim の操作を調整

Vim 設定から、対応する画面やセッションの動作を調整できます。

gg G·Ctrl-f
06 / 単体ビルド

実行ファイルを生成

Ctrl-f·NORMAL
ソースからビルド

oc-vim を使い始める。

リポジトリには OpenCode fork 全体が含まれます。ビルドスクリプトが現在の環境向けに TUI 統合と CLI をコンパイルします。

1. リポジトリをクローン

git clone https://github.com/iamcheyan/oc.git cd oc

2. ビルドして起動

実行ファイルは fork/dist/ に出力されます。Linux x64 の例：

bash fork/build.sh ./fork/dist/oc-vim-linux-x64/bin/oc-vim
